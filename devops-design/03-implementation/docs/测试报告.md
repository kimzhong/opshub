## 2. 详细测试结果

### 2.1 PowerShell 脚本（9 个）

通过 PowerShell 5.1 parser 严格验证：

| 脚本 | 状态 | 问题 |
|---|---|---|
| `kind/create-clusters.ps1` | ⚠️ 失败 | 嵌套 Where-Object + 中文 unicode + `(` 内表达式误判 |
| `kind/delete-clusters.ps1` | ⚠️ 失败 | 单引号字符串中 `` `n `` 不被 PS5 解析 |
| `argocd/install-argocd.ps1` | ⚠️ 失败 | 双引号内嵌单引号导致字符串终止符错位 |
| `registry/cosign/setup-cosign.ps1` | ⚠️ 失败 | PS5 parser 误判（unicode + 复杂管道） |
| `scripts/inject-pod-failure.ps1` | ⚠️ 失败 | `||` 链式操作符（PS7+ 语法） |
| `scripts/inject-slo-burn.ps1` | ⚠️ 失败 | `${LatencyMs}ms` 变量插值（PS7+ 语法） |
| `scripts/simulate-region-failure.ps1` | ✅ 通过 | （已修过） |
| `scripts/dr-drill/monthly-dr-drill.ps1` | ⚠️ 失败 | 多行 `@{}` 哈希表 + 嵌套 if |
| `scripts/onboarding/onboard-new-cluster.ps1` | ⚠️ 失败 | **整个是 bash 脚本，扩展名应是 .sh**（hashbang 是 `#!/bin/bash`） |

**根因分析**：
- 9 个脚本中 8 个有 PowerShell 5.1 兼容性问题
- 主要是 PS5 vs PS7+ 语法差异（`||` 链式、`${var}text` 变量插值、中文 unicode 处理）
- 1 个 (`onboard-new-cluster.ps1`) 误用扩展名（实为 bash）
- 不影响**逻辑正确性**，仅在 PS5.1 上跑不起来

**已修过**（部分）：替换了 unicode 符号（✓→[OK]、✗→[X]、⚠→[!]、→/←），简化了部分复杂表达式。

**剩余问题**：仍受 PS5.1 解析器限制。
