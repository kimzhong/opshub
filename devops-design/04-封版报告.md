| # | 决策 | 选择 | 理由 |
|---|---|---|---|
| 1 | 多集群管理 | ArgoCD（vs Flux）| 生态最广、UI 最成熟 |
| 2 | IaC 双层 | Terraform（基础）+ Crossplane（应用）| 各擅其职 |

## 5. 已知限制

1. **运行时未跑通**：kind 集群创建、Helm chart 部署、ArgoCD 同步、应用 HTTP 访问均未端到端验证。原因是 GitHub TCP 不可达 + kind binary 未安装 + 部分 helm chart 仓库无法访问。
2. **PS1 编码**：脚本中所有输出已转为 ASCII（中文保留在注释），`Get-Content` 默认 ANSI 解码 UTF-8 文件会破坏中文，因此本次实现的修复脚本统一用 Python 写文件以保持 UTF-8。
3. **Mermaid 节点文本限制**：飞书画板的 mermaid 解析器对节点文本中的 `(` `)` `<br/>` 有限制，必须用全角中文括号或换为 ` ` 空格。
4. **画板限流**：飞书画板短时间（< 10s）连续创建会触发 degrade_code=2107，必须 sleep 5-8s。
